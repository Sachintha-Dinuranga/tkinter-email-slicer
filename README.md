# tkinter-email-slicer
A simple and user-friendly Email Slicer application built with Python and Tkinter. Extract username and domain from any email address instantly!

## Features

- **Instant Email Slicing** - Extract username and domain with one click
- **Email Validation** - Validates email format using regex
- **Clean GUI** - Simple and intuitive interface
- **Error Handling** - Proper error messages for invalid inputs
